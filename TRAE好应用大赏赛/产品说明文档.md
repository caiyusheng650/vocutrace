# 词溯（Vocutrace）产品说明文档

> 版本：v1.0.0（2026-11）
> 形态：Android App + 移动端网页，同一套代码
> 本文面向评审与后续迭代，重点说明"如何衡量记住"与"习题如何推荐"，所有数值均与当前代码实现一致

---

## 一、产品概述

词溯是一款面向中考、四级、雅思备考学生的背单词刷题 App，内置三套词书共 10479 条词条（中考 1603 / 四级 3848 / 雅思 5028），每条包含音标、中英释义、词根助记与易混词提示。

产品要解决的核心问题是：传统背单词软件的练习推荐过于粗糙，用户大量时间花在"已经会的词"和"暂时不可能会的词"上，真正处于遗忘边缘的词反而没有被及时复习。词溯的回答是：**把"记没记住"从一个二值判断，变成可量化、可分维度、随时间衰减的状态，再用这个状态驱动每一道题的选择。**

### 目标用户与场景

- 用户：中学生、大学生及雅思备考者，每天可投入 10–20 分钟碎片时间
- 场景：打开即练，不需要自己规划今天背什么；系统按遗忘规律和个人薄弱点自动出题

### 学习闭环

```
定级测试 → 选词书 → 每日任务（新词 + 到期复习）
        → 刷题判分 → 更新记忆状态 → 推荐下一题
        → 错题自动进出错题本 → 周报 / 记忆画像复盘
```

## 二、如何衡量用户"真正记住"了一个单词

这是评审最可能追问的问题。词溯没有用单一标准，而是三层口径互相印证。

### 2.1 第一层：单词级间隔复习状态（SM-2 简化版，免费用户）

每个单词独立维护一份状态：`{ interval 复习间隔(天), reps 连续答对次数, ef 难度系数, dueAt 下次到期时间 }`，初始 `ef = 2.5`。作答后更新规则：

```
答对：reps + 1
      第 1 次答对 → interval = 1 天
      第 2 次答对 → interval = 6 天
      之后        → interval = round(interval × ef)
      ef 微调（下限 1.3）
答错：reps 归零，interval = 1 天，ef 下调 0.2
```

**衡量含义**：一个词不是"答对一次就算记住"，而是必须在**不断拉长的间隔上连续答对**，间隔从 1 天 → 6 天 → 按 EF 倍增，能在更长时间后仍然答对，才算进入长期记忆。答错则整个间隔重置，说明此前的"记住"只是短时记忆。

### 2.2 第二层：单词 × 能力维度掌握度（会员）

"认得"和"写得出"是两种能力，二值状态会掩盖差异。词溯把全部题型映射到三个知识维度（KC）：

| 维度 | 含义 | 对应题型 |
|---|---|---|
| kc1 | 释义识别 | 英选中、英文释义匹配 |
| kc2 | 搭配运用 | 中选英、短句完形 |
| kc3 | 听音 / 拼写 | 拼写题 |

每个"单词 × 维度"独立存一个 0~1 的掌握度，**默认 0.5**：

```
答对：掌握度 +0.15
答错：掌握度 −0.2
自动截断在 [0, 1]
```

**衡量含义**：从默认值到接近 1 大约需要连续 4 次答对；一次答错会抹掉超过一次答对的积累，对失败更敏感。同一个词可能 kc1 = 0.95（看得懂）而 kc3 = 0.35（拼不出），系统由此识别"假性掌握"。

### 2.3 第三层：记忆分层（用户可见的解释口径）

在"我的"页把单词分为三层，规则完全来自真实作答记录：

- **容易溜走**：最近一次作答是错的
- **正在巩固**：最近一次答对，但连续答对不足 2 次
- **稳定记住**：连续答对 ≥ 2 次（含手动标记认识且无错误记录的词）

### 2.4 遗忘概率：让"记住"随时间衰减

上述状态回答"当前掌握得如何"，遗忘概率回答"此刻还剩多少"。按距上次答对的天数计算，半衰期取 7 天：

```
P(遗忘) = 1 − e^(−距上次答对天数 / 7)
从未答对的词：P = 0.5
```

即刚答对时遗忘概率接近 0，越久没复习越接近 1。它是推荐排序的首要驱动因子。

### 小结：三个口径的分工

| 口径 | 回答的问题 | 用途 |
|---|---|---|
| SM-2 间隔状态 | 这个词需要隔多久再考 | 决定到期时间 |
| 维度掌握度 | 这个词的哪种能力薄弱 | 决定出题侧重 |
| 遗忘概率 | 这个词此刻有多危险 | 决定优先顺序 |

## 三、习题推荐方法（新方法）

### 3.1 总体思路

传统方法是"从词表里按顺序取下一个"或"随机抽"。词溯改为**候选池逐题收益打分，取最高分的一题**。每次请求下一题时，为当前词书的候选词各生成一道题，逐题计算收益分，降序排列，取本轮未出过的最高分题。

### 3.2 收益分公式

```
score = 0.4 × P(遗忘)
      + 0.4 × (1 − 该词该维度掌握度)
      − 0.1 × 当日疲劳度
      − 0.1 × 难度偏差
```

四个因子的计算方式：

**① 遗忘概率（权重 0.4）**：见 2.4，越接近遗忘的词越优先。

**② 维度薄弱度（权重 0.4）**：`1 − 掌握度`，掌握越差的维度越该出题，保证练习投向短板而不是舒适区。

**③ 难度偏差（权重 0.1）**：

```
单词难度 = 词书基准（中考 0.2 / 四级 0.5 / 雅思 0.8）
         + (该词在词书中的位置占比 − 0.5) × 0.3
难度偏差 = |单词难度 − 用户水平|
用户水平：零基础 0 / 中级 0.5 / 高级 1（来自定级测试）
```

太简单和太难都会被同一个惩罚项压下去，题目被拉向"略高于当前水平"的区间。

**④ 疲劳度（权重 0.1）**，按自然日重置：

```
疲劳度 = 0.6 × min(1, 当日题数 / 20)
       + 0.4 × min(1, 连续答错题数 / 3)
```

此外，当连续答错 ≥ 3 题或当日做题 > 20 题时，难度偏差会再追加一次惩罚，状态差时主动减少难题，避免劝退。

### 3.3 作答后如何回流

每次作答不只判对错，还会驱动状态更新，形成闭环：

1. 写入作答记录（含对错、耗时、错选项、时间戳）
2. 会员更新对应维度掌握度（+0.15 / −0.2），免费用户更新 SM-2 间隔
3. 重算当日疲劳度
4. 下一题基于新状态重新打分排序

### 3.4 免费与会员的差异（如实说明）

- **免费用户**：SM-2 到期词优先复习，无到期词时随机出题，题型随机——保证基础体验完整
- **会员（看激励广告兑换，无付费墙）**：启用上述四维收益打分与维度掌握度，推荐粒度从"词"细化到"词 × 能力"

## 四、创新点与新旧方法对比

### 4.1 创新点

1. **状态建模创新：从二值到多维**。把"会 / 不会"拆成单词 × 三个能力维度的连续掌握度，能识别"看得懂、拼不出"的假性掌握，这是传统二值模型结构上做不到的
2. **推荐目标创新：从"推进度"到"最大化复习收益"**。每道题用遗忘概率、薄弱度、难度匹配、疲劳度四项联合打分，排在最前面的永远是"此刻最该练且练得动"的题
3. **难度自适应创新：双向惩罚**。难度偏差对过易和过难对称扣分，配合定级水平基准，把题目稳定在最近发展区，而不是只按词表顺序推进
4. **状态感知创新：疲劳度参与排序**。把当日做题量和连续答错纳入模型，用户状态下滑时自动降难度，这是多数背单词产品没有的负反馈保护
5. **商业化与学习目标统一**：会员靠看广告获得而非付费，算法能力向所有愿意付出注意力的学生开放

### 4.2 与传统方法的对比

| 维度 | 传统词表 / 固定间隔方法 | 词溯的方法 |
|---|---|---|
| 单词状态 | 会 / 不会二值 | 单词 × 三维度连续掌握度 + 间隔状态 |
| 出题顺序 | 词表顺序或纯随机 | 全候选池收益打分取最高 |
| 难度控制 | 无，或仅按词书整体分级 | 逐词难度与用户水平匹配，双向惩罚 |
| 复习时机 | 固定天数提醒 | 按词独立的 SM-2 到期 + 7 天衰减遗忘概率 |
| 状态差时 | 无感知，照样推难题 | 疲劳度降权，自动减少难题 |
| "会认不会拼" | 无法识别，不再出题 | 维度独立计分，拼写题自动增多 |
| 用户成本 | 订阅付费解锁功能 | 看激励广告兑换，零现金门槛 |

### 4.3 效果如何被用户观察到

算法不是黑盒，产品内有四个可验证的外化表现：

- 连续答错几题后，后续题目明显变简单（疲劳降权生效）
- 某词"认对拼错"后，同词的拼写类题目占比上升（维度掌握度生效）
- 首页"待复习错词"随 SM-2 到期自动出现，做完即消失
- "我的"页薄弱雷达与学习小结直接指出最弱维度（如"目前最需要补的是拼写"）

## 五、已知局限与演进方向

为避免评审追问时失实，当前版本的局限如实列出：

1. **题型选择仍是随机的**：推荐粒度做到了"词 × 维度"的打分，但具体出哪种题型在可用题型中随机抽取，尚不能主动定向补最弱维度。下一步把题型也纳入打分即可闭合
2. **单词难度是位置代理**：当前用词书内位置估算难度，严格说词序不等于真实难度。计划改用词频数据或全站实测错误率替换
3. **遗忘概率只参考最近一次答对**：近期答错不会直接抬高遗忘概率，仅通过掌握度扣分间接体现，可改为综合多次作答记录
4. **打分权重为人工标定**（0.4/0.4/0.1/0.1）：属于启发式模型而非训练得到的知识追踪模型，代码中已预留对接 KT 模型的上报接口
5. **高级推荐当前仅会员可用**，免费用户为 SM-2 + 随机兜底
6. **性能**：会员每次出题为全词书构建候选题对象（雅思约 5000 词），后续将改为候选集预筛选再打分

## 六、技术架构与工程说明

- **前端**：原生 HTML / CSS / JavaScript + Tailwind（CDN，无构建步骤），Capacitor 7 打包 Android；内容列 max-width 460px 居中，移动优先
- **后端**：零依赖 Node.js，提供邮箱验证码登录、学习数据同步、广告奖励校验；systemd 常驻公网服务器，监听 8787 端口，支持开机自启与崩溃重启
- **数据**：词库静态打包（10479 条）；学习记录本地优先，登录后按 questionId + 时间戳去重合并同步
- **安全**：验证码发送限流与校验次数上限；广告奖励仅在播放完成回调后发放，无 mock 兜底，防止屏蔽脚本白嫖会员
- **设计系统**：低饱和青绿主色 + 带青调灰阶；四级字号、四档中性阴影；卡片 16px / 弹层 24px 圆角；统一 24 网格线性 SVG 图标；所有动效尊重系统"减少动态效果"设置

## 七、附：评审快速验证路径

1. 打开网页版，点「游客体验」→ 选词书与水平 → 完成 6 题定级
2. 连做 10 题以上，观察：选择题点选项即判分、解析展开、底部"下一题"始终在视口内
3. 故意连续答错 3 题，观察后续题目难度下降（疲劳降权）
4. 进入「词书 → 错题本」，确认答错的词已自动进入；回到刷题答对同一词后确认其自动移出
5. 进入「我的」，查看记忆分层、薄弱雷达、能力标签与学习小结
